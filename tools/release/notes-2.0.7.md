# Chatterino Noctis 2.0.7

### Общие изменения

- Тема Noctis Dark теперь автоматически применяется при обновлении и переносе настроек.
- IRC установлен в качестве протокола отправки сообщений по умолчанию.
- Исправлены мелкие ошибки.

### Для модераторов

- Добавлена система независимого обновления модуля автомодерации.
- Расширены возможности настройки автоматических наказаний.
- Исправлена работа мута и размута за баллы канала.
- Добавлена поддержка собственного канала.
- Окна автоответчика больше не блокируют основной интерфейс.
