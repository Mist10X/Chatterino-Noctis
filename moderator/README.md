# Noctis Moderator

Здесь находится подписанный независимо обновляемый модуль для доверенных
модераторов: `module.json` определяет доступ, а `extension.json` — отдельно
обновляемые сценарии и интерфейс. Подмена доступа или несанкционированное изменение модуля запрещены
автором; см. `tools/moderator/AUTHOR-NOTICE.md`.

Инструкции владельца: `tools/moderator/README.md`.
